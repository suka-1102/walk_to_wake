# テスト方針

Vitest で重要なドメインロジックの単体テストのみ書く。網羅率は追わない。実行は `bunx vitest`。

## 書く

`lib/` に置いた純粋関数が対象。

- 2点間の距離計算と、判定半径に対する内外判定
- 期限時刻の判定（日付境界を跨ぐケースを含む）
- ペナルティ額・返金額の計算と早期失敗判定（**境界値のケースを必ず含める**）
- 目標地点の変更回数が上限に達した際に変更を拒否する処理

## 書かない

- 画面の見た目
- Prisma のクエリそのもの
- Auth.js の認証フロー

## 手動確認

位置情報が絡む画面は自動テストしない。Chrome DevTools の Sensors パネルで座標を偽装して手動確認する。
