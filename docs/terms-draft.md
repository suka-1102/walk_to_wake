この利用規約（以下「本規約」といいます）は、本サービス「Walk to Wake」（以下「本サービス」といいます）の利用条件を、本サービスを利用する方（以下「ユーザー」といいます）と本サービスの運営者（以下「運営者」といいます）との間で定めるものです。ユーザーは、本規約に同意した上で本サービスを利用するものとします。

### 第1条（適用・同意）

1. 本規約は、本サービスの利用に関して生じる運営者とユーザーとの間の一切の関係に適用されます。
2. ユーザーが本サービスにログインした時点で、本規約に同意したものとみなします。
3. 本サービスは、位置情報という個人情報を継続的に取得します。個人情報の取扱いについては別途定める「プライバシーポリシー」によるものとし、これも本規約の一部を構成します。

### 第2条（本サービスの内容）

1. 本サービスは、ユーザーが自ら設定した目標地点に、自ら設定した期限時刻までに実際に足を運び、ブラウザの位置情報機能を用いてチェックインすることを、あらかじめ設定したデポジット（預り金）の減額というペナルティによって後押しするものです。
2. 本サービスは、ユーザーを起床させるアラーム機能を持ちません。アラームによる起床後、二度寝せずに外出する動機付けのみを目的とします。
3. ユーザーが同時に進行できるチャレンジ（目標地点・期限時刻・期間・デポジット額の組み合わせ）は1件に限られます。

### 第3条（v1における金銭の扱い）

1. 本サービスの現バージョン（以下「v1」といいます）では、実際の金銭の授受は一切発生しません。
2. ユーザーが設定するデポジット額、チェックイン失敗により生じるペナルティ、これらに基づき計算される残高・返金額・システム利用料は、いずれも本サービス上での**表示上の計算**にすぎず、運営者とユーザーとの間で現実の金銭のやり取りを生じさせるものではありません。
3. 将来のバージョンで決済機能（デポジットの預託・返金を伴う実際の金銭処理）を導入する場合、運営者は本規約及びプライバシーポリシーを改めて見直した上で、別途定める規約により同意を取得します。

### 第4条（チェックインの判定）

1. チェックインの成否は、ユーザーの端末のブラウザから取得した位置情報と、本サービスがあらかじめ定める判定基準（目標地点からの距離、位置情報の精度、受付時間内であること）に基づき、本サービスの計測結果によって判定します。
2. 期限時刻に猶予はありません。理由の如何を問わず、期限を1秒でも過ぎたチェックインは失敗として扱います。
3. 電波状況、端末の設定、GPSの精度その他ユーザーの環境に起因して位置情報の取得ができなかった場合又は測位に誤差が生じた場合であっても、運営者はその結果について責任を負いません。

### 第5条（禁止事項）

1. ユーザーは、本サービスの利用にあたり、以下の行為をしてはなりません。
   1. 位置情報を偽装する等、不正な手段によりチェックインを成立させる行為（v1では技術的な検知・防止を行いませんが、禁止事項として定めます。）
   2. 他のユーザーのアカウントを利用する行為、又は自己のアカウントを第三者に利用させる行為
   3. 本サービスの運営を妨害する行為、又は本サービスのサーバーその他の設備に不正にアクセスする行為
   4. 法令に違反する行為、その他運営者が不適切と判断する行為
2. 運営者は、ユーザーが前項各号のいずれかに該当すると判断した場合、事前の通知なく、当該チャレンジの終了、アカウントの利用停止又は削除その他必要と判断する措置を講じることができるものとします。

### 第6条（中断・一時停止・中途解約の不可）

1. ユーザーは、進行中のチャレンジを中断、一時停止、又は中途解約することはできません。
2. チャレンジをやめたい場合、ユーザーは何もせず放置することができます。この場合、チェックインができなかった日が失敗として積み上がり、後述の早期失敗によりチャレンジが自動的に終了します。

### 第7条（早期失敗によるチャレンジ終了）

1. デポジット残高（デポジット額からそれまでの失敗回数分のペナルティを差し引いた額）が、ペナルティ単価を下回った時点で、当該チャレンジは早期に終了します。
2. 前項の場合、ペナルティ単価に満たない端数の残高は没収され、ユーザーに返金されません（v1では金銭の授受自体が発生しないため、表示上の残高が0として扱われることを意味します。）。
3. チャレンジが終了した後の日は、失敗としてカウントされません。
4. チャレンジが終了した場合、ユーザーは直ちに新しいチャレンジを作成することができます。

### 第8条（アカウント）

1. ユーザーは、Googleアカウントによるログインをもって本サービスの利用登録を行います。運営者独自のパスワードは発行しません。
2. ユーザーは、マイページから表示名（本サービス内でのみ有効な表示上の名称）を変更することができます。これによりGoogleアカウント側の情報が変更されることはありません。
3. ユーザーは、マイページから、確認の上でアカウントを削除することができます。アカウントを削除すると、保存した目標地点、チャレンジ及びチェックインの記録はすべて削除され、復元できません。
4. 進行中のチャレンジがある状態でアカウントを削除した場合であっても、デポジット残高相当額の返金は行われません（v1では金銭の授受自体が発生しないためです。）。

### 第9条（本サービスの停止・変更・終了）

1. 運営者は、以下のいずれかに該当する場合、ユーザーへの事前の通知なく、本サービスの全部又は一部の提供を停止又は中断することができます。
   1. 本サービス又はこれに関連する設備の保守を行うとき
   2. 天災、停電、通信回線の障害その他運営者の合理的な支配が及ばない事由により本サービスの提供が困難なとき
   3. その他運営者が停止又は中断を必要と判断したとき
2. 運営者は、本サービスの内容を変更し、又は本サービスの提供を終了することができます。本サービスを終了する場合、運営者は合理的な期間、本サービス上への掲示その他適切な方法で事前に周知するよう努めます。ただし、緊急の場合はこの限りではありません。
3. 本サービスの停止、変更又は終了により生じたユーザーの損害について、運営者は責任を負いません。

### 第10条（免責事項）

1. 運営者は、本サービスにバグ、不具合又はデータの消失がないことを保証するものではありません。
2. 運営者は、本サービスの利用又は利用不能によりユーザーに生じた損害について、運営者の故意又は重大な過失による場合を除き、責任を負いません。
3. 本サービスの判定はユーザーの端末及び通信環境に依存します。ユーザーの端末設定、電波状況、位置情報の許可設定等に起因してチェックインが成立しなかった場合について、運営者は責任を負いません。
4. v1において本サービスの利用に金銭的な対価は発生しないことを踏まえ、運営者がユーザーに対して負う損害賠償責任は、運営者の故意又は重大な過失による場合を除き、一切発生しないものとします。

### 第11条（知的財産権）

本サービスに関する商標、ロゴその他の知的財産権は、運営者又は正当な権利を有する第三者に帰属します。本規約は、本サービスの利用許諾以外の権利をユーザーに許諾するものではありません。

### 第12条（本規約の変更）

1. 運営者は、必要と判断した場合、ユーザーへの事前の通知なく本規約を変更することができます。
2. 変更後の本規約は、本サービス上に掲示した時点から効力を生じるものとし、掲示後にユーザーが本サービスを利用した場合、変更後の本規約に同意したものとみなします。
3. 本規約の変更内容がユーザーに重大な不利益を及ぼすと運営者が判断する場合は、相当の期間をおいて事前に本サービス上で周知します。

### 第13条（連絡方法）

運営者からユーザーへの連絡は、本サービス上への掲示又はユーザーが登録したGoogleアカウントに紐づく連絡手段のうち運営者が適当と判断する方法により行います。

### 第14条（準拠法・裁判管轄）

本規約の準拠法は日本法とします。本規約及び本サービスに関して紛争が生じた場合には、運営者の住所地を管轄する裁判所を第一審の専属的合意管轄裁判所とします。
