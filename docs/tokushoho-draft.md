# 特定商取引法に基づく表記（ドラフト・v2完成後を想定）

**実装は Stripe 決済を導入する v2 まで待つ。** [terms-draft.md](terms-draft.md)・[privacy-draft.md](privacy-draft.md) と同じ扱い。v1 は対価を得る取引が存在しないため表示義務の対象外（[AGENTS.md](../AGENTS.md) の「v1 を法規制の対象外に保つ設計原則」）であり、このページ自体を公開しない。

## 前提

- 参考にしたページ: [MENTA の特定商取引法に基づく表記](https://menta.work/tokutei)。項目名・並び順はできるだけ MENTA に揃えたが、MENTA は法人（ランサーズ株式会社）運営で、本サービスは個人（作者本人）運営という前提で内容を作り直している
- **運営者は法人ではなく個人。** 特定商取引法上、通信販売の場合は「消費者からの請求があれば遅滞なく開示する」旨を表示することで、住所・電話番号の常時公開を省略できる（個人が自宅住所を公開する必要がない）。このドラフトもその前提で書いた
- **「電話番号」「メールアドレス」は MENTA のページにはないが、本ドラフトには残した。** 住所・電話番号の常時公開を省略する代わりに、法律上、確実に連絡が取れるメールアドレスの表示が必要になるため（省略の要件）。MENTA は法人として住所を公開しているのでこの制約を受けない
- **「動作環境」は MENTA のページになく、特定商取引法上の必須項目でもないため削除した。**
- 運営者の氏名・メールアドレスは未確定。**プレースホルダのまま実装せず、`/tokushoho` を実際に作る段階で本人が確定させる**（[terms-draft.md](terms-draft.md) の「運営者の実名・問い合わせ先は未確定」と同じ論点）
- 販売価格・返金条件は AGENTS.md の「将来の Stripe 連携方針」をそのまま反映した。この方針が変わったら AGENTS.md を直した上でここも直す
- システム利用料率・デポジット額の上下限は `lib/config.ts` の値を埋め込まず、公開時に実際の値を差し込む（AGENTS.md 本文と同じ「しきい値は `lib/config.ts` が正」という原則に合わせる）
- [terms-draft.md](terms-draft.md) 第3条1項にはすでに本ページへのリンクが「［特定商取引法に基づく表記］」というプレースホルダで置かれている。`/tokushoho` を実装するタイミングでそのリンクを実体化し、[screens.md](screens.md) のページ一覧にも `/tokushoho` を追加する

### 販売価格

ユーザーがチャレンジ作成時に設定するデポジット額（〇〇〇〇円〜〇〇〇〇円の範囲）に、デポジット額の〇%（1円未満切り捨て）のシステム利用料を加算した金額。

### 商品価格以外に必要な料金

なし。決済手数料はシステム利用料に含みます。

### 支払い方法について

クレジットカード（VISA/MasterCard/American Express/JCB。Stripe を通じた決済）でのお支払いが可能です。

### 支払い時期

チャレンジを作成し、カード決済が行われたタイミングで課金が発生いたします。

### 商品の提供時期

チャレンジ作成ページにて作成ボタンが押され、カード決済が行われた時点で本サービスの利用（チャレンジの開始）が可能になります。

### キャンセル時の対応

運営者からの返金は原則としてできません。

チャレンジ開始後は、目標地点・期限時刻の変更、中断、一時停止、中途解約はいずれもできません（[terms-draft.md](terms-draft.md) 第6条）。

- チャレンジが期間満了まで継続した場合：デポジット額から、それまでの失敗回数にペナルティ単価を乗じた額を控除した残額を返金します。システム利用料は返金しません。
- チャレンジが早期失敗により終了した場合：デポジット額は返金しません。システム利用料も返金しません。

### 個人情報の取扱いについて

個人情報の取扱いに関しては、[プライバシーポリシー](../app/privacy/page.tsx) をご参照ください。
