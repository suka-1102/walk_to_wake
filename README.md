# Walk to Wake

「絶対に行かなければならない」を、お金の力で実現するコミットメント支援 Web アプリ。

自分で設定した目標地点に、決めた時刻までに実際に足を運ぶ（＝チェックインする）ことを、デポジット（預り金）の減額というペナルティで後押しする。アラームは鳴らさない。

目標地点は自分で設定し、そこに時間内に移動することでペナルティを免れる。

> **v1 の時点では実際の金銭は動かない。** Stripe による決済・返金の連携は v2 以降のスコープで、v1 はペナルティ額の計算と表示までを行う。

仕様・技術スタック・開発規約は [AGENTS.md](AGENTS.md) を参照。
